Scan

Point Ingot at a directory of unknown files. It expands any archives it finds, then for every file: hashes it, scores entropy, verifies the Authenticode signature, computes the PE import hash and an SSDEEP fuzzy hash, checks the NSRL known-good set and the optional known-bad blocklist, runs YARA (with severity scoring and MITRE ATT&CK enrichment) and capa on YARA-flagged binaries (with a FLOSS string + IOC fallback), then clusters the batch by SSDEEP and imphash and drafts a YARA rule per cluster. capa/FLOSS need their standalone binaries — install them on the Settings page.

On the Results grid, right-click any file for a quick-launch menu of analysis tools found in your tools directory (the set is scoped to the OS Ingot is running on), plus Ghidra headless analysis and “Export for AI analysis”.

This path is read on the machine running Ingot. Set it here or on the Settings page.

    About
    
        
    BinSifter Ingot
    
        
    The Rust variant of BinSifter: a local backend service plus this
          browser UI, built to run on any Linux, macOS, or Windows machine without a
          desktop GUI toolkit. Bound to 127.0.0.1 only, no authentication —
          a single-analyst local tool.
